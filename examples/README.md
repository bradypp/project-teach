# Fieldnotes example learning project

Open [.learning/index.html](.learning/index.html). This fictional CSV-export project demonstrates what the teaching workflows maintain. It is not a production implementation or evidence of the real user's learning. Sample creation dates are deliberately varied for sorting.

- **Setup:** [mission](.learning/MISSION.md) and [active plan](PROJECT_PLAN.md) establish purpose and current decisions. Preferences were skipped, so no preferences file is created.
- **Teach:** two substantial lessons cover capacity and retry identity with inspected sources, experiments and application questions.
- **Update:** [state](.learning/LEARNING_STATE.md) links two explicitly synthetic reasoning records; exposure remains distinguished from demonstrated reasoning.
- **Review:** the state retains uncertainty and identifies durable claiming as the next learning need; recall has not been tested.
- **Quiz:** optional choice and written practice, with explanatory feedback and export. Creating it adds no learning evidence.
- **Synthesis:** the topic, reference and glossary connect the ideas without duplicating the evidence ledger.

Source material was inspected on 12 September 2026. Infrastructure examples illustrate boundaries; they do not select a managed service for this project.
