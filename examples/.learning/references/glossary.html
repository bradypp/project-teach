Fieldnotes export service · fictional learning project

Vocabulary from the fictional project’s learning sessions. These entries are examples, not an assessment of your understanding.

Admission · Attempt · Backlog · Backpressure · Idempotency · Operation key

Admission

The decision to accept work now. A request can be refused before it becomes an accepted job.

See it in context

Attempt

One execution try. Several attempts may belong to the same logical job.

See it in context

Backlog

Accepted work still waiting for processing. Count and age reveal different aspects of waiting.

See it in context

Backpressure

A capacity signal that slows or stops a producer. Here, a full pending-job queue triggers waiting or explicit refusal.

See it in context

Idempotency

Repeating the same logical operation preserves the intended effect. Here, a retry should resolve to the same export result.

See it in context

Operation key

An identifier for one export intent, reused by repeat attempts and changed for a genuinely new export.
