Switchboard glossary

A vocabulary aid requested for this example project. These definitions support the lessons; their presence does not imply that a learner has mastered the terms.

Abstention

An explicit decision not to answer because the available evidence does not support the requested claim. Track appropriate abstention separately from unanswered but answerable cases.

See the worked lesson

Checkpoint

A saved graph-state recovery point. It describes progress in an investigation, not permission to perform arbitrary external side effects.

See the worked lesson

Claim generation

A monotonically increasing ownership version. Switchboard includes it in result writes so a superseded worker cannot finish a newer attempt.

See the worked lesson

Context budget

The allowance shared by instructions, history, evidence and reserved output. Retrieval depth and the number of chunks actually packed are separate choices.

See the worked lesson

Coverage

The fraction of evaluation cases on which the agent answers. State the denominator and inspect support among those answers separately.

See the worked lesson

Deadline

The absolute end of a job’s allowed lifetime. Retrying a tool or reclaiming a job does not grant a fresh overall deadline.

See the worked lesson

Idempotency

A repeated logical operation has the intended effect once under its contract. A stable request key needs enforcement and a defined scope, such as tenant plus operation.

See the worked lesson

Lease

Permission to work that expires unless renewed. Expiry lets another worker reclaim the job; it does not physically stop the old process.

See the worked lesson

Retrieval-augmented generation

A generation workflow supplied with retrieved material. The candidates still need access checks, selection and an assessment of whether they support the answer.

See the worked lesson

Replay

Re-execution from a recovery boundary. A repeated read may return changed data even if it has no side effects.

See the worked lesson

Source version

The identity of the exact document revision or observation used in an answer, enabling inspection after the live source changes.

See the worked lesson
