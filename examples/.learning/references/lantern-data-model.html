Keep intake identity separate from attempts and effects

Inbox identity and payload

FieldInvariant or purpose
provider + event_idUnique together; identifies one provider intent.
payloadCanonical bytes retained before acknowledgement.
payload_sha256Exposes the same identity arriving with changed content.
received_atSupports ordering and oldest-event age.
processed_atSet only after the chosen completion boundary is durable.

Processing fields answer recovery questions

FieldRequired behavior
statusConstrain to named states; do not infer a state from several nullable columns.
lease_ownerOnly the current owner may renew or complete a live claim.
lease_untilAn expired value makes interrupted work eligible again.
attempt_countIncrement with the claim so every acquired attempt is observable.
last_errorKeep a bounded diagnostic summary; detailed logs live elsewhere.

Store facts that drive a decision. A field earns its place when intake, claiming, recovery, reconciliation or an operator can state how it changes behavior.
