# Teaching style

Editable preferences for learning through this project. These defaults are copied during setup; change them as your preferences develop.

## Depth

- Teach generously during explicit learning, brainstorming, planning and grilling.
- Supplement specification, ticketing and implementation without displacing their purpose.
- Explain important prerequisites before asking me to make a technical decision.

## Presentation

- Use chat for small explanations, with inline diagrams when helpful.
- Create HTML automatically for substantial gaps; include a link and the original question in chat.
- Prefer clean typography, useful visuals and layouts suited to the concept.
- Use interactive examples when they help me understand, rather than for decoration.

## Pace and practice

- Give each lesson one tangible win; split broad topics into linked manageable lessons.
- Ask a relevant application question, often the question already pending in the workflow.
- Let me answer or continue the project without finishing the artifact.
- Use explanatory feedback and occasional recall/transfer practice.

## Retention

- Save useful lessons; skip tiny clarifications.
- Keep useful unknown unknowns in learning state, including opportunities beyond this project.
- Treat quizzes as optional practice, with no automatic evidence updates.

## Practitioner perspectives

- Occasionally suggest a useful community or practitioner resource when experience would help.
- Keep these suggestions optional.
